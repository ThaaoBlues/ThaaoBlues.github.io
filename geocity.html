Règles du Jeu GeoCity

Principe : Une ville secrète est choisie aléatoirement parmi les villes les plus peuplées du monde (triées par nombre d'habitants).

Options de Pool : Vous pouvez ajuster le Top N par population (de Top 100 à Top 5 000) ou activer le mode ★ Capitales uniquement.

Indices Initiaux : 3 villes aléatoires sont placées sur le radar. Leurs vecteurs partent du centre (la ville secrète) pour indiquer leur distance exacte et leur direction cardinale.

  • Mode Classique : Le nom et le pays des 3 villes indices sont affichés directement sur le radar.
  • Mode Hardcore : Les noms des 3 indices sont masqués (Indice #1, #2, #3) pour une triangulation pure.

Triangulation : Chaque ville que vous proposez ajoute un nouveau vecteur coloré selon sa proximité jusqu'à ce que vous trouviez la cible.
