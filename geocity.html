Règles du Jeu GeoCity

Principe : Une ville secrète est choisie aléatoirement parmi une base de données mondiale de milliers de villes.

Indices Initiaux : 3 villes aléatoires sont placées sur le radar. Leurs vecteurs partent du centre (la ville secrète) pour indiquer leur distance exacte et leur direction cardinale.

  • Mode Classique : Le nom et le pays des 3 villes indices sont affichés directement sur le radar.
  • Mode Hardcore : Les noms des 3 indices sont masqués (Indice #1, #2, #3) pour une triangulation pure.

Propositions : À chaque essai, un nouveau vecteur coloré s'ajoute depuis le centre selon votre proximité :

  • Vert : Très proche (< 800 km)
  • Orange / Jaune : Distance modérée (800 - 2 500 km)
  • Rouge : Éloigné (> 2 500 km)
